# Latar Belakang

Keberadaan **Internet of Things (IoT)** ini membuat penggunaan smart device makin marak, baik itu untuk rumah, perkuliahan maupun kantor. Namun, manajemen terhadap penggunaan perangkat ini menjadi masalah, dimana pengguna mesti memanfaatkan aplikasi lain untuk setiap perangkat. Sehingga, proses monitoring akan menjadi tidak efektif dan sulit mendapatkan gambaran menyeluruh mengenai kondisi seluruh perangkat.

Namun demikian, permintaan akan monitoring real-time dan pengambilan keputusan cepat semakin tinggi. Ironisnya, hampir semua aplikasi IoT yang ada hanya menawarkan fungsi dasar monitoring dan kontrol tanpa menyediakan analisis untuk memastikan pengguna bisa mengantisipasi masalah tersebut.

Berangkat dari kesempatan tersebut, **MBG (Manage Beyond Grid)** hadir sebagai solusi dalam bentuk platform manajemen perangkat IoT yang memadukan **Cloud Computing** dan **Artificial Intelligence (AI)** pada satu aplikasi mobile. MBG memudahkan pengguna untuk melakukan monitoring dan kontrol atas perangkat-perangkat berdasarkan cloud dan memanfaatkan kekuatan dari AI untuk mendeteksi ancaman, memprediksi potensi gangguan, serta memberikan rekomendasi yang membantu pengguna mengelola perangkat dengan lebih efisien dan proaktif.


# MBG (Manage Beyond Grid)

**MBG (Manage Beyond Grid)** merupakan sebuah aplikasi mobile yang dibangun menggunakan teknologi **Flutter**. Fungsi utama dari MBG adalah mempermudah para penggunanya dalam mengelola, memonitor, dan mengendalikan berbagai perangkat **Internet of Things (IoT)** di bawah satu platform terpadu. Penggabungan antara **Cloud Computing** dan **Artificial Intelligence (AI)** oleh MBG membuat proses pemantauan, analisa, dan pengambilan keputusan dengan lebih cepat dan efisien.


# Fitur Utama

## Smart Dashboard

Menampilkan seluruh perangkat IoT dalam satu dashboard sehingga pengguna dapat melihat status perangkat secara real-time tanpa perlu membuka banyak aplikasi.

## Remote Device Control

Memungkinkan pengguna mengontrol perangkat IoT dari mana saja melalui internet, seperti menyalakan, mematikan, atau mengubah konfigurasi perangkat.

## Cloud Synchronization

Seluruh data perangkat disimpan dan disinkronkan melalui cloud sehingga dapat diakses kapan saja dan dari berbagai perangkat.


## AI Smart Insights

Artificial Intelligence menganalisis data perangkat untuk mendeteksi kondisi yang tidak normal, memprediksi potensi gangguan, serta memberikan rekomendasi yang membantu pengguna mengambil keputusan.


## Smart Alert & Notification

Mengirimkan notifikasi secara otomatis ketika terjadi kondisi penting, seperti perangkat offline, suhu terlalu tinggi, atau konsumsi daya yang tidak normal.


## Analytics & Reports

Menyediakan laporan penggunaan perangkat dalam bentuk grafik dan statistik yang mudah dipahami, seperti penggunaan energi, waktu aktif perangkat, dan riwayat aktivitas.
